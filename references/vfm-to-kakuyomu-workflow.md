# カクヨム投稿用変換ワークフロー

## 概要

VFM形式の .md 原稿をカクヨム記法に変換する手順。

カクヨムのエピソード本文で使える独自記法は**ルビ**と**傍点**の2つだけ（[カクヨム記法](https://kakuyomu.jp/help/entry/notation)）。太字・斜体・見出し・画像・生HTMLは本文では機能しない。本手順では、VFM で執筆した原稿を各エピソードの本文欄に貼り付け可能なプレーンテキストに変換する。

### 記法対比表

| VFM / Markdown 記法 | カクヨム記法 | 備考 |
|---------------------|-------------|------|
| `{漢字\|かんじ}` | `｜漢字《かんじ》` | 全角縦線 ｜ を必ず付ける |
| `{電子出版\|でん\|し\|しゅっ\|ぱん}`（熟語分割） | `｜電《でん》｜子《し》｜出《しゅっ》｜版《ぱん》` | 親文字数＝ルビ数なら各文字に分割 |
| `{日本語\|にほんご}`（グループルビ） | `｜日本語《にほんご》` | そのまま1つのルビ |
| `《《テキスト》》`（傍点） | `《《テキスト》》` | 同一記法。そのまま使える |
| `<em class="emphasis-dot">…</em>` | `《《テキスト》》` | VFM の HTML 傍点を変換 |
| `===`（3つ以上の `=`） | `◇`（場面転換記号） | カクヨムに改ページなし。`--scene-break` で変更可 |
| `## 一`（本文中の見出し） | `一`（`#` を外して本文に残す） | 見出し記法は表示されないため |

### 除去・テキスト化される VFM 要素

| VFM 記法 | 処理 |
|---------|------|
| YAML frontmatter (`---`で囲む) | 削除 |
| 原稿先頭の見出し（`# 章タイトル`） | 削除（投稿画面のエピソードタイトルへ転記） |
| `[^1]` / `[^1]: 定義`（脚注） | 本文中に括弧注として統合 |
| `**太字**` / `*斜体*` | テキスト化（カクヨムに太字・斜体なし。警告を出す） |
| `![alt](ファイルパス)`（画像） | `[※挿絵N]`（通番。カクヨム本文に画像は掲載不可） |
| `[テキスト](URL)` | `テキスト（URL）`（カクヨムで自動リンクになるのはカクヨムURLのみ） |
| `<https://…>`（自動リンク） | 裸のURL |
| `~~打ち消し~~` | テキスト化 |
| `> 引用` | テキスト化（`>` を除去） |
| コードブロック・テーブル・リスト | テキスト化 |
| HTMLコメント `<!-- -->` | 削除（カクヨムでは文字として表示される） |
| `[%N]`（ページジャンプ） | 削除 |

### カクヨムの制約（変換時の落とし穴）

- **ルビと傍点は併用不可** — `《《｜漢字《かんじ》》》` のように入れ子にすると表示が壊れる。スクリプトはルビを優先して傍点を外し、警告を出す
- **ルビは最大20文字 / ルビ文字は最大50文字** — `validate_kakuyomu()` が超えた箇所を警告する
- **記法は改行をまたぐと無効** — 親文字とルビ、傍点の開始と終了は同じ行に置く
- **本文に画像を掲載できない** — 挿絵は近況ノートで共有し、`[※挿絵N]` プレースホルダーは投稿時に削除する
- **生HTMLは使えない** — `<br>` なども文字として表示される。段落間の空行は空行のままでよい
- **記号を表示させたい場合** — `《` の直前に `｜` を置いて `｜《` と書くと、そのまま表示される

## 前提条件

- `novel/` ディレクトリに VFM 形式の .md 原稿が完成していること（推敲C完了）
- 変換スクリプト `scripts/vfm_to_kakuyomu.py` が利用可能であること

## スクリプト

`scripts/vfm_to_kakuyomu.py` を使用する。

## 使い方

単一ファイルの変換:

```
python3 scripts/vfm_to_kakuyomu.py novel/ch01.md -o kakuyomu/ch01.txt
```

一括変換:

```
for f in novel/*.md; do
  python3 scripts/vfm_to_kakuyomu.py "$f" -o "kakuyomu/$(basename "$f" .md).txt"
done
```

場面転換記号を変える場合（既定は `◇`）:

```
python3 scripts/vfm_to_kakuyomu.py novel/ch01.md --scene-break '＊' -o kakuyomu/ch01.txt
```

標準出力には変換結果、標準エラーに情報と警告が出る。

- `[INFO] エピソードタイトル候補:` — 原稿先頭の見出し。投稿画面のエピソードタイトル欄に転記する
- `[INFO] 文字数:` — 変換後の本文の文字数
- `[WARN] …` — 変換で落とした要素（太字・画像など）とカクヨム制約の違反。原稿側で直す（Upstream Fix）

## 投稿手順（エピソード単位）

カクヨムは**エピソード単位**の投稿で、変換も章ファイル単位（`novel/chNN.md` → `kakuyomu/chNN.txt`）。章の大見出し／小見出しは投稿画面で設定する。

1. ワークスペース → 「小説を作成」→ 基本情報（タイトル・あらすじ・ジャンル）を入力
2. 「章とエピソード」タブで章（大見出し／小見出し）を追加
3. 各エピソードの本文欄に `kakuyomu/chNN.txt` の中身を貼り付ける
4. エピソードタイトルに `[INFO]` の候補を入力する
5. プレビューでルビ・傍点の表示を確認する
6. 必要ならセルフレイティング（「残酷描写有り」「性描写有り」等）を設定する
7. AI の利用状況に応じてタグ（AI本文利用 / AI本文一部利用 / AI補助利用）を付ける（[カクヨム小説投稿ガイドライン](https://kakuyomu.jp/legal/guideline)）
8. `[※挿絵N]` プレースホルダーが残っていれば削除する

## 変換後確認ポイント

変換結果を目視で確認し、以下の点をチェックする:

- **ルビ** — `｜` が付いているか。熟語分割（`{日常生活|にちじょうせいかつ}` → `｜日常生活《にちじょうせいかつ》`）や複合ルビ（`{電子出版|でん|し|しゅっ|ぱん}`）が意図どおりか
- **傍点** — `《《》》` の対応が取れているか（改行をまたいでいないか）
- **ルビ×傍点の併用** — 警告が出た箇所を手で直したか
- **画像プレースホルダー** — `[※挿絵N]` の位置と通番が正しいか
- **見出し** — 先頭の `# 章タイトル` が消え、投稿画面で設定するタイトルと一致しているか。本文中の `## 一` は `一` として残っているか
- **改ページ・場面転換** — `===` の位置に `◇` が入っているか

## 既知の制限

- **画像**: カクヨム本文に画像は掲載できない（作品ページ・エピソードページとも）。挿絵は近況ノートで共有する。`[※挿絵N]` は投稿時に削除する
- **脚注**: 括弧注形式で本文中に挿入される。カクヨムには脚注機能がないため、読者は文脈内で読む形式になる
- **装飾の制約**: 太字・斜体・打ち消し線・引用・コードブロック・テーブル・リストはプレーンテキスト化される。強調したい箇所は傍点 `《《…》》` への書き換えを検討する（`writing-workflow.md` 側で決める）
- **URL**: カクヨムで自動リンクになるのはカクヨムの URL のみ（本文・紹介文限定、アプリでは未実装）。他サイトの URL はただの文字列になるため、`テキスト（URL）` 形式で残す
- **傍点の種類**: カクヨムの傍点は `《《》》` の1種類のみ。ゴマ点・白丸などの使い分けはできない
