# pixiv小説投稿用変換ワークフロー (Step γ)

## 概要

VFM形式の .md 原稿を pixiv 小説タグ形式に変換する手順。

pixiv は `[newpage]` `[chapter:タイトル]` `[b:太字]` `[i:斜体]` `[ruby:漢字|よみ]` 等の独自タグを採用している。
本手順では、VFM で執筆した原稿を pixiv 小説投稿画面に貼り付け可能なプレーンテキスト形式に変換する。

### 記法対比表

| VFM / Markdown 記法 | pixiv 小説タグ |
|---------------------|---------------|
| `{漢字\|かんじ}` | `[[rb:漢字 > かんじ]]` |
| `{電子出版\|でん\|し\|しゅっ\|ぱん}`（熟語分割） | `[[rb:電 > でん]][[rb:子 > し]][[rb:出 > しゅっ]][[rb:版 > ぱん]]` |
| `{日本語\|にほんご}`（グループルビ） | `[[rb:日本語 > にほんご]]` |
| `===`（3つ以上の `=`） | `[newpage]` |
| `## 第一章` | `[newpage]` + `[chapter:第一章]` |
| `### 第一節` | `[chapter:第一節]` |
| `**太字**` | `[b:太字]` |
| `*斜体*` | `[i:斜体]` |
| `《《テキスト》》`（傍点） | `[[emphasismark:テキスト>﹅]]` |
| `![alt](12345678)`（pixiv ID） | `[pixivimage:12345678]` |
| `[テキスト](https://example.com)` | `[[jumpuri:テキスト > https://example.com]]` |
| `[%2]` | `[jump:2]` |

### 除去される VFM 要素

| VFM 記法 | 処理 |
|---------|------|
| YAML frontmatter (`---`で囲む) | 削除 |
| `# タイトル`（h1） | 削除 |
| `[^1]` / `[^1]: 定義`（脚注） | 本文中に括弧注として統合 |
| `![alt](ファイルパス)`（画像） | 削除 |
| `~~打ち消し~~` | テキスト化 |
| `> 引用` | テキスト化 |
| コードブロック・テーブル・リスト | テキスト化 |

## 前提条件

- `novel/` ディレクトリに VFM 形式の .md 原稿が完成していること（推敲C完了）
- 変換スクリプト `scripts/vfm_to_pixiv.py` が利用可能であること

## スクリプト

`scripts/vfm_to_pixiv.py` を使用する。

## 使い方

単一ファイルの変換:

```
python3 scripts/vfm_to_pixiv.py novel/第1章.md -o pixiv/第1章.txt
```

一括変換:

```
for f in novel/*.md; do
  python3 scripts/vfm_to_pixiv.py "$f" -o "pixiv/$(basename "$f" .md).txt"
done
```

## 変換後確認ポイント

変換結果を目視で確認し、以下の点をチェックする:

- **脚注** — 正しく本文に統合されているか（括弧注形式で文中に挿入される）
- **ルビ** — 特に熟語ルビ（例: `{日常生活|にちじょうせいかつ}` → `[ruby:日|に][ruby:常|じょう][ruby:生|せい][ruby:活|かつ]` に分割）が正しく分割されているか
- **h1/frontmatter** — 除去されているか（pixiv 投稿では不要）
- **装飾タグ** — `[b:]` `[i:]` `[[emphasismark:]]` が正しく変換されているか
- **画像ファイルパス** — 除去されているか（pixiv ではイラスト ID を別途指定する必要がある）
- **改ページ・章見出し** — `[newpage]` と `[chapter:]` の配置が正しいか

投稿画面での作業（タイトル・タグ・プレビュー等）は `references/pixiv-export.md`「pixiv投稿時の追加作業」。

カクヨム向けの変換は `references/vfm-to-kakuyomu-workflow.md`（記法も投稿手順も別物。カクヨムの独自記法はルビと傍点のみ）。

## 既知の制限

- **画像**: pixiv ではイラスト ID が必要。ファイルパスは変換時に除去されるため、投稿後に手動で `pixivimage:XXXXX` タグを挿入する必要がある
- **脚注**: 括弧注形式（例: 「用語（説明文）」）で本文中に挿入される。原注脚注とは異なり、読者は文脈内で読む形式になる
- **装飾の制約**: 打ち消し線・引用・コードブロック・テーブル・リストはプレーンテキスト化される。必要に応じて投稿後の手動調整が必要
- **傍点（《《》》）**: 原稿中の `《《テキスト》》` は pixiv の `[[emphasismark:テキスト>﹅]]` に変換される。EPUB/PDF 組版時には `《《》》` マーカーが除去されテキストのみ残る。EPUB で圏点が必要な場合は `<em class="emphasis-dot">` を HTML 直書きする
